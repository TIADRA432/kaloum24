Base de données non initialisée

Les tables du site n'existent pas encore.

Depuis le dossier du projet, avec l'environnement virtuel activé :

flask db upgrade
flask seed-db     # facultatif : contenu de démonstration

Si flask répond « No such command 'db' », c'est que la variable FLASK_APP n'est pas définie :

  1. Linux / macOS : export FLASK_APP=app.py
  2. Windows (cmd) : set FLASK_APP=app.py
  3. Windows (PowerShell) : $env:FLASK_APP="app.py"

Vérifie aussi que l'environnement virtuel activé est bien celui de ce dossier, et non celui d'une copie précédente du projet. Pour connaître le fichier de base réellement utilisé :
python -c "from app import create_app; print(create_app().config['SQLALCHEMY_DATABASE_URI'])"
